# 检验结果（2026-09-29）

两部分：扫描脚本的误报率和检出率；改稿模式是否守住信息。

## 1. 扫描脚本

### 语料

| 组 | 来源 | 文档数 | 汉字 |
|---|---|---|---|
| human | HC3-Chinese 的 open_qa、medicine、psychology 子集人类回答（知乎式问答、在线问诊医生回复） | 12,078 | 约 198 万 |
| gpt35 | 同一数据集的 ChatGPT（GPT-3.5，2022–2023）回答 | 5,803 | 约 127 万 |
| claude_qa | Claude（2026-09 版）回答从上述三个子集随机抽取的 60 个问题（每子集 20 个，seed=7），不加任何风格指令 | 60 | 约 5 万 |
| claude_article | Claude 按"帮我写一篇小红书笔记 / 公众号科普文章"写的 12 篇儿科、影像科普，不加风格指令 | 12 | 约 1.1 万 |

只统计汉字数 ≥50 的回答。Claude 语料在 `corpus/`，问题清单在 `corpus/claude_qa_questions.json`。其中有 4 篇回答在初稿后由生成它的 agent 做过事实修正（删掉不确定的片名、史实），没有改动用词风格。

### 结果

"判为偏高"：任一实测特征超过人类基线两倍（人类基线低于 0.1/千字的稀有特征，出现 1 处即算；相邻句同构要求 3 处以上）。

| 组 | 文档数 | 任一实测项判为偏高 |
|---|---|---|
| human | 12,078 | **3.4%**（误报率） |
| gpt35 | 5,803 | 18.9% |
| claude_qa | 60 | **85.0%** |
| claude_article | 12 | **83.3%** |

分项文档触发率：

| 特征 | human | gpt35 | claude_qa | claude_article |
|---|---|---|---|---|
| 空转句引出列表 | 0.4% | 5.0% | 65.0% | 41.7% |
| 顿号罗列 | 0.9% | 10.1% | 37.5% | 33.3% |
| 序数词当小标题 | 0.0% | 0.0% | 20.0% | 50.0% |
| 提示性冒号 | 0.8% | 0.1% | 10.0% | 16.7% |
| 段首零回指评论 | 0.1% | 0.1% | 3.3% | 8.3% |
| 破折号 | 0.2% | 0.3% | 1.7% | 8.3% |
| 翻案腔 | 0.2% | 0.1% | 5.0% | 0.0% |
| 相邻句结构同款 | 0.7% | 3.9% | 3.3% | 0.0% |
| 起手式 | 0.2% | 0.0% | 1.7% | 0.0% |
| 拟人化职业喻体 | 0.0% | 0.0% | 0.0% | 0.0% |

共识特征（只标位置，不计入判定）每千字：GPT-3.5 的"综上所述"类总结词 0.55、"包括…等" 0.50、句首"此外/因此" 1.30，人类分别为 0.03、0.03、0.05；Claude 两组这三项都接近 0。

### 读法

- **Claude 的 AI 味在格式和结构上**：空转句引列表、序数小标题、顿号罗列三项贡献了绝大部分检出。套话词几乎没有。
- **GPT-3.5 的 AI 味在词上**：套话、总结词、句首连接词。实测特征里只有顿号罗列和空转句有区分力，所以检出率只有 18.9%。要查这类旧模型的稿子，看共识特征的命中位置更有用。
- **翻案腔是新模型的习惯**：GPT-3.5 用得比人类还少（0.05 对 0.25/千字）。lieflat 测的新版 GPT 是 1.26/千字。
- **破折号随版本变化**：lieflat 测到的 claude-opus-4-6 是 4.25/千字，2026-05 的真实 Claude 稿件是 7–8/千字，2026-09 版只有 0.1–0.6/千字。

### 检验中做过的调整

第一轮人类误报率是 7.0%。逐条看误报样例后做了这些修改，修改后为 3.4%：

| 问题 | 修改 |
|---|---|
| "是不是有人…是不是…"被当成"不是…是…" | 翻案腔正则排除"是不是""还不是" |
| 分隔线"————"、箭头"——》"被当成破折号 | 排除连续 3 个以上和后接箭头的 |
| 正文里的"第三，…"短行被当成小标题 | 中文序数标题只认"一、""（一）""第一章/部分/节/步" |
| "问题：""建议：""原因："在人类医生回复里同样常见（人类 0.02–0.03/千字，GPT-3.5 0.07–0.09） | 从提示性冒号里去掉这三个裸标签 |
| "第一句话：「……」"引出原话被当成提示冒号 | 冒号后紧跟引号的不算 |
| "出现下面任一条，立刻挂神外门诊："被当成空转句 | 引导句带就医行动指令的不算 |
| 相邻句同构在短回答里容易凑出 2 处 | 门槛提到 3 处 |

这些调整是看过同一批数据之后做的，所以 3.4% 偏乐观。前六项是修正则错误，第七项是调阈值。

## 2. 改稿模式

### 第一轮

一个 agent 加载 skill，按改稿模式改写 6 篇 Claude 科普稿（3 篇小红书、3 篇公众号）；另一个没看过 skill 的 agent 做医学编辑式的逐句核查，默认立场是"假定改写者偷偷改了东西"。

| 篇目 | 实测项（改前→改后） | 字数 | 新增事实 | 删除信息 | 强度/主次变化 | 安全呈现问题 |
|---|---|---|---|---|---|---|
| xhs_01 | 2→1 | 590→567 | 0 | 0 | 0 | 0 |
| xhs_03 | 1→0 | 662→652 | 0 | 0 | 0 | 0 |
| xhs_05 | 0→0 | 767→725 | 0 | 0 | 0 | 0 |
| wx_01 | 1→0 | 1068→998 | 0 | 0 | 1 | 0 |
| wx_03 | 3→2 | 1116→1033 | 0 | 1 | 0 | 1 |
| wx_06 | 1→0 | 1353→1239 | 0 | 0 | 0 | 1 |

没有新增任何事实，数字、剂量、用药年龄限制、就医清单全部保留。发现的问题：

1. wx_06 删掉了"❌ 掐人中""❌ 喂水、喂药"的 ❌，错误做法变成了和正确步骤同样格式的粗体祈使句。
2. wx_03 删掉了全文唯一的兜底就医提示；危险信号的加粗被去掉，良性特点的加粗却保留了。
3. wx_01 把"剂量是关键，孕周也有影响"改成"先看剂量，再看孕周"，主次被拉平。
4. 系统性地去掉了粗体，包括几处安全信息。

改后仍判为偏高的 3 项（顿号罗列 2、空转句 1）都是医学清单，按规则有意保留。另外，把列表并成段落后，顿号罗列的计数反而上升（脚本不数列表行），这是正确改动的副作用，已写进规则说明。

**据此对 skill 做的修改**：硬约束第 2 条加入"主次也是强度"和"安全信息的醒目程度不降低"（❌ 类否定标记去掉时必须改成文字否定；危险信号和就医指征的加粗保留；唯一的兜底就医提示不删）；改稿模式第 3 步的核对清单加入这几项；B14 注明带语义的符号不是装饰。

### 第二轮

用修改后的 skill 重改出问题的 3 篇，逐项核对第一轮的问题：

| 篇目 | 实测项（改前→改后） | 第一轮问题 | 第二轮 |
|---|---|---|---|
| wx_06 | 1→0 | ❌ 被删，错误做法成了祈使句 | 已修复：5 条都改成"别…"开头（"别掐人中""别喂水、喂药"） |
| wx_03 | 3→1 | 删掉兜底就医提示；危险信号去粗、良性特点留粗 | 已修复：保留"有疑问及时就医"；加粗只留在危险信号清单上。剩下 1 项是症状清单的顿号罗列，有意保留 |
| wx_01 | 1→0 | "剂量是关键，孕周也有影响"被拉平 | 部分修复：保留了"关键看剂量和孕周……孕周也有影响"，但"剂量是关键"这层强调弱了 |

第二轮只做了定向核对，没有再跑一次完整的独立核查。改写稿和两轮核查材料在 `rewrite/`。

## 3. 流水线审核模式

用一部真实的 AI 竖屏医疗短剧剧本（第 1 集，141 个汉字的台词和字卡）试跑。输出的 JSON 字段完整，可被多镜片流水线解析；结论 pass、8 分，2 条 P2、2 条 P3，涉及题眼句和知情同意场景的两条标了 needsOwner。它正确保留了有意的重复（集名动作"鞠躬"）、集尾碎句和合规文字，并把剧情、医学、字幕技术问题转给了对应镜片。试跑暴露的六处说明不清（没有"台词"文体、合规字卡审不审、分数锚点太少、剧情功能句的边界、字数上限依据、location 格式）已补进 SKILL.md。剧本本身未公开。

## 4. 局限

- 人类对照组是问答语料，不是带小标题的长文章。公众号、新闻、学术摘要上的误报率没测过，序数小标题一项在长文上的误报可能更高。
- Claude 语料 72 篇，每个特征的触发率置信区间很宽。
- 只测了 Claude 和 GPT-3.5。DeepSeek、Qwen、Kimi、豆包没有测。
- 改稿检验只有 6 篇，核查者也是模型，不是人类医学编辑。
- 扫描器只测形式特征。缺具体材料、结构模板化、立场空泛这些语义层问题，要靠 skill 的通读检查，没有量化检验。
