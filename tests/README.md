# 测试样本

三份文件都是 Claude 为验证扫描脚本而写的，不是真实的人机语料，只能说明脚本逻辑正确，不能说明检出率。

- ai_sample.md：故意堆满 A、B 组特征的儿童发热科普。预期：翻案腔、提示性冒号、起手式、序数词小标题、拟人化职业喻体、段首零回指 6 项判为高。（"以下几种情况需要立即就医："带就医指令，按检验后的规则不算空转句）
- ai_sample_rewritten.md：按改稿模式改过的版本。预期：实测项全部"正常"；剩下的翻案腔（纠正"发热是病"这个真实误解）、模糊归因（按规则保留归属，交作者补出处）、顿号罗列（观察项清单是必要信息）都是有意保留。
- human_sample.md：口语化的门诊叙述。预期：实测项全部为 0。
